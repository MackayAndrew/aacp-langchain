# aacp-langchain

**AACP coordination layer for LangChain multi-agent workflows.**

AACP replaces natural language agent-to-agent instructions with typed,
validated, deterministic packets. LangChain handles agent lifecycle,
memory, and tooling. AACP handles what the agents say to each other.

## Install

```bash
pip install aacp-langchain
```

## Quick start

```python
from aacp_langchain import AACPOrchestrator

orch = AACPOrchestrator(model="gpt-4.1-mini")
result = orch.run_workflow("it_provisioning", username="j.smith")
print(result.summary())
```

## What this does

```
Without aacp-langchain:
  Orchestrator
    ↓ "Please ask the HR agent to retrieve salary records for March 2026..."
  LLM
    ↓ "HR Agent, could you fetch the employee salary data?"
  HR Agent
    ↓ "Thank you. Finance Agent, please calculate payroll for these employees..."
  LLM
    ...

With aacp-langchain:
  Orchestrator
    ↓ FETCH|HR|return:ORCHESTRATOR|p:1|aacp:1.1|res:emp_salary|period:2026-03  ($0.00)
  HR Agent  ✓ validates
    ↓ MERGE|HR|return:ORCHESTRATOR|p:1|aacp:1.1|rules:payroll_v2              ($0.00)
  Finance Agent  ✓ validates
    ↓ LOG|HR|return:AUD-Agent|p:2|aacp:1.1|status:review_required             ($0.00)
  Audit Agent  ✓ deterministic
```

LLM calls happen only in agents doing actual work, not in coordination.

## Workflows

```python
# Payroll (5 hops)
result = orch.run_workflow("payroll", period="2026-03")

# IT provisioning / JML onboarding (6 hops)
result = orch.run_workflow(
    "it_provisioning",
    username="j.smith",
    dept="Engineering",
    licences=["M365", "Slack"],
)

# Sales qualification (5 hops)
result = orch.run_workflow(
    "sales_qualification",
    lead_id="L-001",
    lead={"budget_gbp": 75000, "timeline_months": 3, ...},
)
```

## WorkflowResult

```python
result.summary()        # formatted text summary
result.total_cost       # USD cost for LLM agent calls
result.total_tokens     # input tokens across all hops
result.hops             # list of HopRecord (packet, result, cost, latency)
result.outputs          # structured output from each workflow stage
result.to_dict()        # full result as JSON-serialisable dict
```

Every hop is validated against the AACP v1.1 schema before dispatch.
Full audit trail written to `output/audit.jsonl`.

## Packet encoding cost

All packets are generated by rule-based encoders from the `aacp` SDK.
Encoding cost for known workflows: **$0.00**.
The LLM is never called to generate coordination instructions.

## Requirements

- Python 3.10+
- OpenAI API key (`OPENAI_API_KEY`)
- `pip install aacp-langchain`

To use Anthropic models:
- `pip install aacp-langchain[anthropic]`
- `ANTHROPIC_API_KEY`

## Relationship to aacp

This package builds on the [aacp SDK](https://github.com/MackayAndrew/aacp).
It adds LangChain-native orchestration on top of the core protocol.

- AACP spec and Python SDK: https://github.com/MackayAndrew/aacp
- TypeScript SDK: https://github.com/MackayAndrew/aacp-ts
- Community rules (241): https://github.com/MackayAndrew/aacp-community-rules
- IETF Draft: https://datatracker.ietf.org/doc/draft-mackay-aacp/
